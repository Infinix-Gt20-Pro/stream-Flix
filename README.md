# STREAMFLIX — Next.js Cinema Platform

A modern, responsive, Netflix-inspired dark-themed streaming platform built with **Next.js (App Router)**, **TypeScript**, and **Tailwind CSS**.

---

## ✨ Features

- 🌌 **Premium Dark Palette**: Deep cinematic blacks (`#060608`), surface grays, and electric crimson accent (`#E50914`) with neon glow effects.
- 🪟 **Glassmorphism Navigation**:
  - **Desktop Sidebar**: Fixed left glassmorphic navigation with active pill indicators, quick search, notifications, and profile status.
  - **Mobile Bottom Bar**: Fixed bottom glassmorphic bar for thumb navigation on handheld screens.
  - **Sticky Top Bar**: Dynamic blur header with search input, notifications, and instant category filters.
- 🎬 **Cinematic Hero Banner**:
  - Full-bleed media banner with multi-layer radial vignettes.
  - Title, match percentage, 4K UHD & Dolby Atmos badges, and synopsis.
  - Interactive **Play** and **More Info** action buttons.
  - Audio mute/unmute preview toggle.
- 🎡 **Horizontal Scrolling Carousels**:
  - **Trending Now** (Portrait cards)
  - **Top 10 Today** (Giant Netflix-style ranked 1-10 numbered typography)
  - **Blockbuster Movies** (Widescreen backdrop cards)
  - **Binge-Worthy Series**
  - **Sci-Fi & Action Thrillers**
  - Desktop: Left/right smooth navigation arrows with auto-hide.
  - Mobile: Native momentum touch swiping with snap alignment.
- 🍿 **Interactive Video Player / Detail Modal**:
  - Triggered by clicking **Play** or any movie poster card.
  - Video preview simulation with play/pause and scrubber.
  - Full cast, audio options, subtitles, and rating breakdown.

## 🚀 Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Start Development Server
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser.

### 3. Build for Production
```bash
npm run build
npm start
```
